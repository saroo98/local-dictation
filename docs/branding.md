# Local Dictation branding

The owner supplied the Dictation D artwork on 2026-10-04. Imported artwork is
unchanged: violet `#6250C8`, charcoal `#252335`, and white variants for dark
surfaces. Horizontal wordmarks contain outlined glyphs and require no font
download. The source wordmark uses Inter; its supplied license is retained in
[`assets/branding/Inter-OFL.txt`](../assets/branding/Inter-OFL.txt).

- `desktop/public/branding/` contains SVG artwork shared by the interface,
  browser favicon and GitHub README.
- `desktop/src-tauri/icons/` contains supplied Windows artwork. The ICO includes
  15 sizes from 16 to 256 pixels. PNGs provide the configured 32, 128 and 256
  pixel native sizes; `icon.png` is the supplied 256 pixel image.
- The native window, tray, application executable, packaged backend, installer
  and uninstaller use the same application icon.
- The bubble and sidebar use the white mark on its violet background, retaining
  contrast across all appearance presets. Recording, transcription, paste and
  error states retain their operational symbols.

Use the supplied variants at their original aspect ratio. Logo usage does not
declare a license for this project or transfer ownership of the artwork.
